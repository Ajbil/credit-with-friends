# credit-with-friends

CreditWithFriends is a validation MVP for India. People in a trusted circle
list which bank cards they hold, and a shopper can find a holder and open a
WhatsApp chat. The app never collects card numbers.

## Working in this repo

This repo uses [Symphony Forge](https://github.com/knacklabs/symphony-forge).
Open an agent session in the repo root and run `forge next` to see the current
step. Forge handles story and fix branches, checks, and pull requests; the
human approves stories and merges by default.

Start with [the agent instructions](AGENTS.md),
[the product brief](docs/product/BRIEF.md),
[accepted decisions](docs/decisions/), and
[the architecture](docs/architecture/). The coding standards remain in
[the constitution](constitution/README.md), with the MVP deviations recorded
in [decision 0014](docs/decisions/0014-mvp-constitution-deviations.md).
