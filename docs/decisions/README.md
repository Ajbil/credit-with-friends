# Decision Docs

Accepted decisions in this directory bind product and engineering changes.
Read them alongside the [product brief](../product/BRIEF.md), the
[architecture](../architecture/), and the [constitution](../../constitution/README.md).

Use `forge decision new <slug>` to create a proposed record. After the human
confirms it, use `forge decision accept <slug> --by "<name>"`. Run `forge next`
for the current workflow step.

Keep the Context, Decision, and Consequences in each record. Supersede an
accepted choice with a new decision instead of silently rewriting its history.
